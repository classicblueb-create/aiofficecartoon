# แนะนำ connector

## วิธีเช็กก่อนแนะนำเสมอ
1. เรียก ListConnectors ดูว่าผู้ใช้ต่ออะไรอยู่จริงใน session นี้ และเครื่องมือของแต่ละตัว
2. สำหรับตัวที่ยังไม่ต่อ ใช้ SearchMcpRegistry ค้นว่ามีตัวต่อไหม แล้ว SuggestConnectors ให้ผู้ใช้เพิ่มเอง
3. ถ้าไม่มีตัวต่อ ให้บอกตรง ๆ และเสนอทางเลือก (ผู้ใช้ทำเอง, ลิงก์ในกระดานงาน, นำเข้าไฟล์) ห้ามแกล้งว่าต่อได้
4. ความสามารถของตัวต่อเปลี่ยนได้ ตรวจรายการเครื่องมือจริงก่อนสัญญาอะไรกับผู้ใช้

## ตารางแนะนำตามบทบาท
สถานะในคอลัมน์ขวาเป็นค่าที่เคยเห็นในการสร้างครั้งก่อน ต้องยืนยันด้วย ListConnectors ทุกครั้ง

| บทบาท/งาน | ตัวต่อที่เหมาะ | หมายเหตุ |
|---|---|---|
| กระดานงานและแถบสถานะ | Notion | แกนหลักของออฟฟิศ สร้างฐานข้อมูลงาน ต้องมีเสมอ |
| ค้นเทรนด์ คู่แข่ง ข้อมูลเว็บ | Apify, ค้นเว็บ | Apify คิดค่าใช้จ่ายตามการใช้งาน ผลส่วนใหญ่เป็นบล็อกของผู้ขายเครื่องมือ ต้องระวังความลำเอียง |
| เขียนเอกสาร สคริปต์ ข้อเสนอ | Claude Docs, Google Docs/Drive, หน้าใน Notion | เลือกที่ผู้ใช้เปิดบ่อย ค่าเริ่มต้นคือหน้าใน Notion |
| เก็บไฟล์ ผลงาน | Google Drive | ถามโฟลเดอร์ปลายทางก่อนสร้างไฟล์ |
| วางแผน นัดโพสต์ นัดลูกค้า | Google Calendar | ค่าเริ่มต้นคือร่างนัดในกระดาน สร้างนัดจริงหลังเจ้าของสั่ง |
| เสียงพากย์ ถอดเสียง ออกแบบเสียง | ElevenLabs | เวอร์ชันที่ต่ออาจทำได้แค่เสียงและถอดเสียง ไม่มีวิดีโอ/ดนตรี ใช้เครดิตของผู้ใช้ ต้องอนุมัติก่อนและให้ผู้ใช้เลือกเสียง |
| หาลูกค้า ติดต่อธุรกิจ | Vibe Prospecting (ถ้าต่อ) | ใช้เครดิต ต้องอนุมัติก่อนค้นจำนวนมาก ห้ามส่งข้อความหาใครเอง |
| โค้ด เว็บ รีโป | GitHub | สร้างสาขา/ร่างเท่านั้น ห้ามรวมโค้ดเอง |
| ตาราง ตัวเลข ใบเสนอราคา | Google Sheets (ถ้ามี) | ถ้าไม่มีตัวต่อ ใช้ตารางใน Notion แทน และบอกผู้ใช้ |
| ข้อความลูกค้า (LINE, Slack, อีเมล) | ตามที่มีตัวต่อจริง | ห้ามส่งออกเอง ให้ร่างข้อความไว้ในกระดานให้เจ้าของกดส่ง |
| โพสต์ลงโซเชียล | ไม่มีตัวต่อให้ใช้โพสต์ในหลายกรณี | ให้ทีมเตรียมไฟล์และแคปชั่น เจ้าของโพสต์เอง |

## หลักการแนะนำ
- แนะนำเท่าที่จำเป็นกับวงจรงานของเขา เริ่มจากน้อยตัว (ปกติ Notion บวกอีก 1 ถึง 3 ตัว) แล้วค่อยเพิ่ม
- ทุกตัวต้องบอก 3 อย่าง: ทำอะไรให้ทีมไหน, อ่านอย่างเดียวหรือเขียนด้วย, มีค่าใช้จ่ายหรือไม่
- ตัวที่เขียนข้อมูลออกนอก (ส่งข้อความ สร้างนัด โพสต์ ใช้เครดิต) ให้ผูกกับด่านอนุมัติเสมอ
- ผู้ใช้ต้องเชื่อมต่อและอนุญาตเองที่หน้าตั้งค่า connector ของ claude.ai ห้ามขอรหัสผ่านหรือโทเคน
- ตอนเผยแพร่แดชบอร์ด ประกาศเฉพาะเครื่องมือที่ใช้จริงในหน้านั้น (ไม่ประกาศกว้างเกินจำเป็น)
