# คำสั่งสำหรับ Claude Code

อ่าน `README.md` และ `BRIEF.md` ก่อนเริ่ม ผู้ใช้ชื่อ Classicblue (modty.ai) ตอบเป็นภาษาไทย กระชับ

## งานหลัก
สร้างภาพ plate "ออฟฟิศทีมช่วยงาน" สไตล์เดียวกับ statechart-art (pen & coloured pencil) โดย:
1. โคลน https://github.com/kevintngo/statechart-art แล้วทดสอบ `node business/art/order.js --fast` ให้ผ่านก่อน
   (ต้อง `mkdir -p business/out` และ `cd tools && npm install`)
2. ใช้โมเดล `models/W6.tla` (ออฟฟิศ) เป็นแกน เขียน `view.mjs` ให้คำของแต่ละสถานะ/ก้าวเป็นภาษาไทย
   ทำ chart (Mermaid) → จัด layout ด้วย pele → วาดด้วย `tools/kit` + `tools/lib/people.js`
3. ทำตามแบบ `order.js`: ตั๋วปักหมุด ด้ายแดง ตัวคนหน้าครีมแก้มชมพู เสื้อพาสเทล ใช้จานสีใน `BRIEF.md`
4. เริ่มจากภาพเดียวแบบแบน แล้วถามผู้ใช้ก่อนทำไอโซเมตริกหรือคลิปวาดตัวเอง
