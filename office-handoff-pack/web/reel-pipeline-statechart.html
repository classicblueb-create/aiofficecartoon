IIช่องโหว่ที่ TLC เจอ

ในโมเดลที่เขียนตามตัวอักษรของ SKILL.md

เส้นทางสั้นที่สุดที่ทำให้กฎพัง (5 ก้าว)
  1. เลือก format: split
  2. ถอดเสียงเป็น word timestamps
  3. เขียน scene plan ข้ามขั้นตรวจซับไปเลย
  4. ขอรูปจากผู้ใช้
  5. build โดยซับไทยยังไม่ถูกตรวจ

SKILL.md เขียนว่า “always proofread the Thai text” แต่ขั้นตอนใน workflow ไม่ได้บังคับเป็นด่านก่อนเขียนแผน เลยเป็นแค่ขั้นที่ข้ามได้ ทางแก้คือใส่ด่านนี้ไว้ก่อน WritePlan พอแก้ในโมเดลแล้ว TLC ผ่านครบ

ข้อควรรู้: นี่คือช่องว่างในข้อความของ skill ตามที่ผมโมเดล ไม่ได้บอกว่าตอนรันจริงจะพลาดเสมอ

ดูโมเดล TLA+ (ย่อ) 
ChooseFormat   == intake -> format chosen
Transcribe     == format chosen -> transcribed
ProofreadThai  == transcribed, proofread = TRUE   \* ข้ามได้
WritePlan      == transcribed -> planned
                  /\ (GateProofread => proofread)
AskForAssets   == planned -> assets requested
Build          == assets requested -> built
                  /\ format # "cutout" \/ matte = "ok"
Render         == built -> rendered, flags in {0,1}
FixFlags       == rendered /\ flags = 1 -> built
Deliver        == rendered /\ flags = 0 -> delivered
                  /\ disclosed' = (placeholders > 0)
